This is not the utility feeder used in the paper's case study (Section IV); it is
a public substitute used only to make this repository runnable end-to-end
without exposing proprietary utility data. Ckt5 is a synthetic ~3,000-bus
Southern-US-representative distribution feeder that EPRI built and released
specifically for PV hosting-capacity research, so it exercises the same
model features as the paper's case study (radial 3-phase primary, unbalanced
single-phase laterals, single-phase service transformers, residential and
commercial customer classes with real hourly annual load shapes).
